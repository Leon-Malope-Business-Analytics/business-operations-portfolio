# Retail Sales Performance Dashboard

## Overview

This project analyses a **simulated** retail transaction dataset to practise business operations analysis, KPI reporting, and management recommendations.

## Business question

How can a retail manager monitor sales performance and identify areas that may need further investigation?

## Tools

* Microsoft Excel
* PivotTables, formulas, and charts

## Dataset

The dataset is fictional. It contains order dates, regions, sales channels, product categories, quantities, unit prices, discount rates, and fictional sales representatives.

## Planned deliverables

* Excel workbook with calculated sales and profit estimates
* Dashboard with key performance indicators and charts
* Short report summarising findings and recommendations

## Method

1. Validate and inspect the transaction data.
2. Calculate gross sales, net sales, estimated costs, and estimated profit.
3. Summarise performance by month, category, region, and channel.
4. Build a dashboard and write evidence-based recommendations.

## Limitations

Estimated cost is assumed to be 65% of gross sales for practice. Estimated profit is therefore a simplified learning metric, not actual accounting profit. All records are simulated.
